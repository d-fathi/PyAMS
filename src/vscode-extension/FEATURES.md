# PyAMS Features

## Graphical Schematic Designer
- Intuitive drag-and-drop interface for circuit design
- Auto-wiring and smart connection detection
- Support for internal ports (Input, Output, Bidirectional)
- Voltage Bar elements for power rails

## Advanced Simulation Engine
- Powered by ngspice (v46) for accurate simulations
- DC Analysis: Operating point and DC sweep
- AC Analysis: Frequency response and Bode plots
- Transient Analysis: Time-domain simulations
- UIC (Use Initial Conditions) support for precise control

## Interactive Waveform Viewer
- Real-time graph visualization with Plotly
- PNG export for reports and documentation
- HTML viewer with print and save support
- Multi-trace analysis

## Extensive Component Library
- **Passive Components:** Resistors, Capacitors, Inductors
- **Semiconductors:** BJT (NPN/PNP), MOSFET (VDMOS), JFET, MESFET
- **Diodes:** Standard, Zener, Photo Diode, Laser Diode, DIAC
- **Integrated Circuits:** OP-AMP library, LM311, LM393 (Voltage Comparators)
- **Optoelectronics:** Photo Diode and Laser Diode macro models

## Developer Features
- Netlist editor with syntax highlighting
- SPICE library panel in sidebar
- Direct file opening from library to editor
- Automatic wire naming based on port names

## Cross-Platform Support
- Windows 64-bit (.exe)
- Linux (.deb and .AppImage for Ubuntu, Debian, Mint, Xubuntu, Lubuntu)
- macOS support (coming soon)
